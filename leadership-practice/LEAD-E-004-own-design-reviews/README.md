# LEAD-E-004: Own design reviews

**Kind:** explicit | **Type:** evidence kit | **Soft skill:** True

## Evidence from posting
own design reviews

## Rationale
Quality gate on others' designs.

## Acceptance / proof
Design-review facilitation checklist and sample review notes.

## Owns
The live design-review facilitation gate: a stated decision goal, required options and risks, correct participants, a timeboxed discussion, an explicit disposition, and same-day durable notes.

## Does not own
Coaching a designer's reasoning progression (LEAD-I-003), an individual mentoring playbook (LEAD-E-003), or written communication at async RFC/runbook scale (LEAD-I-002).
