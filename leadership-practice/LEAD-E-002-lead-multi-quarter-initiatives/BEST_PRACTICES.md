# LEAD-E-002 — Lead multi-quarter initiatives

## Best practices
- Write the initiative end-state and explicit non-goals before turning work into a schedule.
- Slice the program into quarterly outcomes that create usable value and reduce big-bang delivery risk.
- Make each slice traceable from design decision through production evidence and consumer adoption.
- Publish decision rights and a re-alignment cadence so cross-functional partners can resolve scope changes quickly.
- Reserve capacity for enabling platform foundations while stating which desirable work is deferred.
- Evaluate each quarter by shipped capability and observed consumer outcome, then revise later slices.

## Four habits
1. Re-state the end-state and non-goals at every quarterly boundary.
2. Ship one independently useful outcome in each planned slice.
3. Record scope and sequencing decisions with an owner and date.
4. Re-plan future slices from production evidence, not sunk-cost pressure.
