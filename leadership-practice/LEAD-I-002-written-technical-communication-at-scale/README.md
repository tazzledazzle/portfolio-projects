# LEAD-I-002: Written technical communication at scale

**Kind:** implicit | **Type:** evidence kit | **Soft skill:** True

## Evidence from posting
design reviews, patterns, translation, multi-DC org

## Owns
Written communication that lets many teams discover, review, and apply platform decisions asynchronously: an RFC/ADR/runbook set plus evidence of uptake.

## Does not own
Live design-review facilitation (LEAD-E-004) or translating one decision into paired engineering and executive artifacts (LEAD-E-013).

## Rationale
Async docs are the lever for org-wide platforms.

## Acceptance / proof
RFC/ADR/runbook kit with uptake checklist.

- `BEST_PRACTICES.md` — bulleted practices + four habits
