# LEAD-E-008 — Drive continuous improvement

## Best practices

- Operate a recurring review cadence with an explicit baseline, target, owner, and evaluation date.
- Rank observed workflow bottlenecks by consumer impact and evidence rather than by solution novelty.
- Limit each cycle to a testable change and one primary outcome metric so the result can inform the next decision.
- Convert a proven improvement into a safer platform default, template, check, or documented golden path.
- Publish negative or neutral results and retain the baseline so teams do not repeat ineffective work.
- Keep this backlog separate from one-incident postmortem actions and from multi-quarter program commitments.

## Four habits

1. Review the improvement backlog on the same cadence with consuming-team evidence present.
2. Select one bottleneck metric and record its baseline before changing the system.
3. Time-box each change and define a keep, revise, or revert decision in advance.
4. Publish the measured result and update the platform default only when evidence supports it.
